# AI 编程中的软件工程

一份个人学习手册，探索如何学习传统软件工程知识，并将它们转化为 AI 辅助开发中的判断、约束和验证。

从需求、设计、验证到协作和复盘，关注知识如何改善真实项目中的开发过程。

## 阅读入口

[精简目录与编写约定](目录.md)

目前已整理为 6 章，后续按章补充实践案例、模板与学习记录。

## 六个核心问题

1. AI 能写代码后，我还需要掌握什么？
2. 如何让 AI 解决我真正想解决的问题？
3. 怎样让生成的代码便于理解、修改和扩展？
4. 如何判断代码真的满足要求？
5. 如何把软件工程知识放进日常 AI 开发流程？
6. 怎样通过阅读、实践与复盘形成自己的方法？
